What you’re allowing

Chrome’s debugging permission lets this extension observe received messages in the Discord tab you select. Chrome displays a debugging notice while capture runs.

Only identified DMs and group DMs are archived. Server channels, outgoing login tokens, HTTP bodies and credentials are ignored. Captured messages upload to your paired Afterword archive.

Keep Chrome and Discord Web open. Native desktop/mobile messages, missed events and earlier deleted content cannot be recovered here. This unofficial integration may break or conflict with Discord’s platform policies.
